# 🏥 AI-Powered Doctor Appointment Scheduler

An intelligent Hospital Management System built using **Python, Django, Machine Learning, LangChain, FAISS, and MySQL**. The system automates appointment booking, patient management, doctor scheduling, AI-powered assistance, medical records, and predictive analytics to improve hospital operations.

---

# 📌 Project Overview

The AI-Powered Doctor Appointment Scheduler is a complete healthcare management platform designed to simplify hospital workflows through Artificial Intelligence.

The application enables patients to book appointments, doctors to manage schedules, administrators to monitor hospital activities, and AI to assist with appointment booking, medical report analysis, and patient support.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Packiyalakshmikiruba/Doctor-Appointment-Scheduler-AI.git
```

## Open Project

```bash
cd Doctor-Appointment-Scheduler-AI
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Apply Migrations

```bash
python manage.py migrate
```

## Create Superuser

```bash
python manage.py createsuperuser
```

## Run Server

```bash
python manage.py runserver
```
